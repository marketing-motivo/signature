How to add your signature to your email

  1. Click Copy signature above.
  2. In Gmail, open Settings (the gear) and choose See all settings.
  3. On the General tab, scroll to Signature, create a new one, and paste.
  4. Set it as the default for new emails and replies, then click Save changes at the bottom of the page.
  1. Click Copy signature above.
  2. In Front, click the gear icon, open the Personal settings tab, and select Signatures.
  3. Click Add a signature. Give it a name (only you see this) and choose which channels can use it.
  4. Paste into the signature text box, then click Create.
  5. To use it automatically, set it as the default signature for each channel you send from.

If the layout looks off after pasting, switch the text box to HTML, paste the result of Copy HTML code instead, and save. On a shared inbox, your personal signature replaces the team's shared one.
